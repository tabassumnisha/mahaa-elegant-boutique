# Mahaa Elegant Boutique

Build a complete premium luxury e-commerce website redesign concept for the Bangladeshi modest-fashion brand “MAHAA”.

IMPORTANT:
This is NOT a generic fashion template.
This must feel like a real premium/luxury fashion brand website designed specifically for MAHAA.

FIRST:
Study the existing MAHAA website and preserve its real business structure, product categories, brand identity, contact information and e-commerce purpose.

Reference website:
https://mahaa.com.bd/

Official YouTube:
https://youtube.com/@mahaabymustarin

Official Facebook:
https://www.facebook.com/profile.php?id=61586071427160

Natore outlet Facebook:
https://www.facebook.com/profile.php?id=61592707243988

The supplied MAHAA logo and outlet photographs are the primary brand references.

==================================================
1. BRAND IDENTITY — HIGHEST PRIORITY
==================================================

Use the ORIGINAL MAHAA logo exactly as supplied.

DO NOT:
- redraw the logo
- distort the logo
- change its proportions
- replace it with an AI-generated logo
- alter the typography
- change the silhouette/icon
- place it inside an unnecessary box
- create a fake logo variation

Remove the unnecessary background around the supplied logo where appropriate and use it as a clean transparent brand asset.

The logo must remain sharp, proportional and recognizable everywhere.

Create a consistent luxury visual identity based on the existing MAHAA logo and physical outlet branding.

Primary visual direction:
- deep black / charcoal
- MAHAA gold
- warm champagne / ivory
- subtle neutral tones
- elegant shadows
- cinematic photography
- refined gold accents

Do NOT use random bright blue, green or unrelated UI colors.

Gold should be an elegant accent, not an overwhelming color.

==================================================
2. DESIGN PHILOSOPHY
==================================================

Create a:
PREMIUM + LUXURY + CINEMATIC + MODEST FASHION + MODERN E-COMMERCE

experience.

The website should feel closer to a high-end fashion editorial website than a basic online shop.

Use:
- large editorial photography
- generous whitespace
- elegant typography
- subtle gold lines
- premium cards
- smooth hover states
- cinematic transitions
- refined micro-interactions
- subtle reveal animations
- image zoom on product hover
- horizontal product sliders
- elegant section transitions

Avoid:
- cheap gradients
- excessive rounded cards
- childish animations
- excessive glassmorphism
- random colors
- generic SaaS UI
- template-looking layouts
- excessive borders
- visual clutter

The final result must look expensive, sophisticated and trustworthy.

==================================================

- reusable components

20. IMPORTANT ASSET RULE
==================================================

Use the supplied MAHAA logo as the master logo asset.

The logo must NEVER be generated by AI.

Use transparent PNG/SVG-style treatment wherever possible.

The logo must visually integrate into:
- header
- hero
- footer
- loading screen if used
- favicon/brand mark
- promotional sections
