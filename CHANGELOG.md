# Changelog

## 1.0.0 (2026-11-14)
First release of Aurea Atelier, a full-stack fashion store.
- Storefront: dresses and gowns, abayas and kaftans, hijabs and scarves, coats and outerwear. Size, length and colour options, fabric and fit filters, style finder, bag drawer, wishlist, checkout, order confirmation.
- Customer accounts with order history. Admin panel with overview chart, product manager and order manager (Processing, Packing, Dispatched, Delivered, Cancelled).
- Dependency-free Node 22 API with SQLite, server-side pricing and stock control, CSRF checks, rate limits and 21 automated tests.
- Demo mode with 18 sample products and 22 sample orders; one-click "Sign in as Admin" and "Sign in as Customer" buttons.
- Vercel demo entry (`api/index.mjs`), Docker, Render blueprint and a plain-VPS guide.
